# Tiếng Việt Drill — ベトナム語 入力＆発音 練習アプリ

アクティブリコール方式でベトナム語のフレーズを覚える、ビルド不要の静的 Web アプリです。
イメージ画像と日本語訳を先に見て「思い出してから」フレーズが表示され、読み上げ → 音声認識 → 入力判定へと進みます。

## 学習の流れ

1. **イメージ画像・日本語訳・カウントダウン**が表示される（ベトナム語はまだ伏せられたまま = アクティブリコール）
2. 声調記号を含むフレーズなら、表示の直前に **TELEX ヒント**が toast で出る（例: `ế → ees`）
3. ベトナム語フレーズが表示され、**2 回自動で読み上げ**（2 回目はゆっくり）
4. 読み上げ後は自動で **音声入力モード**に切り替わり、話した内容を認識
5. キーボードで正しく入力できたら次のフレーズへ

## 画面の構成（上から）

- イメージ画像
- ベトナム語フレーズ（遅れて表示 / 入力に合わせて 1 文字ずつ色が変わる）
- 入力欄とマイクボタン
- 日本語訳
- 品詞分解（語・品詞・意味・補足）と、フレーズ全体の文法説明

## 操作

| 操作 | 内容 |
| --- | --- |
| `Enter` | 答え合わせ（伏せられている場合はフレーズを表示） |
| `Ctrl` / `⌘` + `Enter` | スキップ（後で再出題） |
| 🔊 / 🐢 | もう一度読み上げ / ゆっくり読み上げ |
| 🎤 | 音声入力の開始・停止 |
| 💡 | TELEX ヒント（打鍵の並びも表示） |
| ⚙️ | 待ち時間・読み上げ速度・自動化・音声の選択 |

設定は `localStorage` に保存されます。

## TELEX 早見表

| 記号 | 打ち方 | 例 |
| --- | --- | --- |
| `â ê ô` | 同じ母音を 2 回 | `aa` → â |
| `ă` | `a` + `w` | `aw` → ă |
| `ơ ư` | 母音 + `w` | `ow` → ơ |
| `đ` | `d` を 2 回 | `dd` → đ |
| 声調 sắc `́` | + `s` | `as` → á |
| 声調 huyền `̀` | + `f` | `af` → à |
| 声調 hỏi `̉` | + `r` | `ar` → ả |
| 声調 ngã `̃` | + `x` | `ax` → ã |
| 声調 nặng `̣` | + `j` | `aj` → ạ |

組み合わせると `ees` → ế、`awf` → ằ のようになります。判定は大文字小文字と句読点を無視しますが、**声調記号は区別**します。

## 動作環境

- 読み上げ（SpeechSynthesis）: 主要ブラウザ。OS にベトナム語の音声が入っていない場合は読み上げが無音になります（Windows は「設定 > 時刻と言語 > 音声認識」から音声パックを追加）。
- 音声認識（SpeechRecognition）: **Chrome / Edge のみ**。マイクの許可と、`https` または `localhost` での配信が必要です。
- 未対応ブラウザでもキーボード入力の練習は問題なく動きます。

## ローカルで動かす

音声認識を試すにはセキュアコンテキスト（`localhost`）が必要なので、簡易サーバー経由で開いてください。

```bash
python -m http.server 8123
```

その後 `http://localhost:8123/` を開きます。

## GitHub Pages へのデプロイ

ビルド不要のため、リポジトリの中身がそのまま公開されます。

```bash
git add -A && git commit -m "Add Vietnamese typing drill app" && git push -u origin main
```

その後、GitHub のリポジトリで **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。`.github/workflows/deploy.yml` が `main` への push を検知して自動デプロイします。

> Actions を使わず「Deploy from a branch」を選ぶ場合も、`main` / `root` を指定すればそのまま公開できます（`.nojekyll` を置いてあるので Jekyll の処理は入りません）。

公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。相対パスのみを使っているので、サブディレクトリ配信でも設定変更は不要です。

## フレーズを追加する

`js/data.js` の配列に追記するだけです。

```js
{
  vi: 'Tôi rất thích phở.',
  ja: '私はフォーが大好きです。',
  art: { main: '🍲', sub: ['❤️', '🌿'], colors: ['#ffd9a0', '#e4572e'], caption: '好きなもの' },
  words: [
    { w: 'Tôi',   pos: '代名詞', ja: '私',       note: '' },
    { w: 'rất',   pos: '副詞',   ja: 'とても',   note: '形容詞・心理動詞の前に置く' },
    { w: 'thích', pos: '動詞',   ja: '好む',     note: '' },
    { w: 'phở',   pos: '名詞',   ja: 'フォー',   note: '米の麺料理' }
  ],
  note: '説明文をここに書きます。'
}
```

TELEX ヒントは `vi` から自動生成されるので、記述は不要です。
